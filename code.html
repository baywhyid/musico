HTML Entities

HTML entities adalah kode khusus yang digunakan untuk menampilkan karakter, simbol, atau spasi cadangan pada halaman web. Kode ini diawali dengan tanda ampersand (&) dan diakhiri dengan titik koma (;).

Berikut beberapa contohnya:

&#9776; untuk hamburger menu (☰)

&#169; untuk copyright symbol (©)

&#10003; untuk centang (✓)

&#10004; untuk check bold (✔)
